# 高级用法
## 一、自定义主题
MkDocs 的主题决定了文档网站的整体风格和布局。默认主题已经满足了大部分需求，但有时我们需要根据品牌或者特殊需求自定义主题。

### 1. 通过配置文件定制
- 你可以在 mkdocs.yml 中修改主题配置，比如颜色、字体和导航样式。以 Material 主题为例，它支持丰富的配置项，如颜色方案、字体选择、代码高亮风格等。

### 2. 覆盖静态资源 
- 如果需要更精细的样式调整，可以在项目根目录创建 docs/overrides 文件夹，将自定义的 CSS、JavaScript 或图片放入相应路径，MkDocs 会覆盖默认主题中的资源。

### 3. 自定义模板
- MkDocs 主题基于 Jinja2 模板引擎。你可以创建或修改 HTML 模板文件，实现对页面结构的自定义，比如添加页脚信息或调整导航菜单。

### 4. 使用第三方主题
- 除了官方主题，还有很多优秀的第三方主题可以使用。你只需安装并在配置文件中启用即可。

### 5. 注意事项
- 修改主题后，请清理浏览器缓存并重新构建文档，以确保样式生效。使用浏览器开发者工具可以帮助定位样式问题。

## 二、文档部署
### 1.部署GitHub Pages
* 确保你的项目在GitHub 仓库(如果你不想在github上保存源代码,那么只要创建github仓库即可)
* 在本地使用以下命令：

```ymal
mkdocs gh-deploy
```
该命令会自动构建项目并将 site 目录内容推送到 GitHub Pages 分支。

### 2. 部署到其他静态服务器
* 将 site 目录内容上传到你的服务器对应的静态资源目录即可。

## 三、性能与构建优化
为了提升用户访问文档的体验和加快本地构建速度，我们建议从以下几个方面进行优化：

1. 合理拆分文档内容:
    - 将大型文档拆分成多个小章节，避免单个文件过大，提升构建效率和页面加载速度。

2. 控制插件数量
    - 仅启用必要的插件，减少构建时的额外处理。部分插件会显著影响构建时间。

3. 资源优化
    - 优化图片大小，减少 CSS 和 JS 文件体积。建议使用现代格式如 WebP。

4. 使用 CI/CD 自动构建与部署
    - 通过自动化流程减轻本地负担，确保构建环境一致。

5. 版本升级
    - 定期更新 MkDocs 和插件，获取性能改进和新功能。

6. 解决常见问题
    - 如果遇到构建速度慢或主题加载问题，可尝试禁用插件或更换主题进行排查。
