# 操作指南
## 一、新增页面
### 1.背景:
当你需要补充新的文档内容，如新增功能说明、FAQ、教程章节等，就需要新增页面。

### 2.基本流程:
- 在 docs/ 目录下创建新的 Markdown 文件
- 编写页面内容（添加标题和正文）
- 在 mkdocs.yml 配置文件中将新页面加入导航
- 本地预览或构建站点，确认页面显示正常

### 3.详细流程:
1. 创建 Markdown 文件
    - 进入项目中的 docs/ 目录
    - 新建一个 .md 格式的文件，例如 new-feature.md
    - 建议文件名使用小写字母和短横线，避免大小写和空格问题

2. 编写页面内容
    - 打开新建的 Markdown 文件,添加一级标题，标题会作为页面的标题显示在浏览器和导航中
    - 注意：文件名和页面标题不必完全相同，页面标题以 Markdown 中的一级标题为准。
3. 将页面加入导航
    - 打开项目根目录下的 mkdocs.yml 文件
    - 找到 nav 配置项
    - 按照导航层级，新增对应页面的路径（相对于 docs/ 目录）
```ymal
    nav:
        - 首页: index.md
        - 新功能:
            - 新功能介绍: new-feature.md
```
重要：如果不将页面加入 nav，该页面不会显示在左侧导航栏。

4. 预览页面效果
    - 在命令行执行：`mkdocs serve`
    - 打开浏览器，访问默认地址 http://127.0.0.1:8000
    - 在左侧导航栏找到新增页面
    - 点击确认内容显示正常

## 二、使用和切换主题
### 1. 主题简介
* 主题决定了文档站点的整体视觉风格和布局。MkDocs 默认提供了几个内置主题，也支持第三方主题，如广受欢迎的 Material 主题。你可以在 MkDocs 官方文档查看更多主题信息。
### 2. 配置主题
* 文件位置: 
    - 主题配置写在项目根目录下的 mkdocs.yml 文件中，通过 theme 关键字指定。
* 使用内置主题

```ymal
    theme:
        name: mkdocs
```


## 三、更改Favicon图标
1. 在docs_dir中创建一个img子目录
```bash
    cd docs
    mkdir img
```  
2. 并将自定义的favicon.ico文件复制到该目录。 
3. MkDocs将自动检测并使用该文件作为你的favicon图标。
