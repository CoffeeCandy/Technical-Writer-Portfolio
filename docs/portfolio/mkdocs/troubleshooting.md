## 常见问题与故障排查

### YAML 使用注意事项

* 使用 **空格** 进行缩进，**不能使用 Tab**
* 缩进层级必须保持一致
* 冒号后必须有一个空格

> ⚠️ 缩进错误是 MkDocs 初学者最常见的问题之一，通常会导致构建失败。


## 导航问题
| 问题现象       | 可能原因             | 解决建议                         |
| ---------- | ---------------- | ---------------------------- |
| 导航栏不显示新增页面 | 未在 `nav` 中添加对应条目 | 确认 `mkdocs.yml` 中 `nav` 配置正确 |
| 构建报错       | 文件路径错误或大小写不匹配    | 检查路径拼写和文件是否存在                |
| 导航层级显示异常   | YAML 缩进错误        | 确认使用空格缩进且层级对应                |
