# 简介

## 一、什么是MkDocs
* MkDocs 是一个以文档为中心的静态站点生成工具，它将内容、结构和样式清晰分离：内容用 Markdown 编写，结构通过配置文件定义，样式由主题控制。它的设计目标是降低文档维护成本，让开发者和文档工程师可以专注于内容本身。

## 二、使用人群
* 技术文档编写者 
* 技术开发人员
* 运维和产品团队

## 三、主要特性
### 1. 简单清晰
* 文档内容与配置分离,文档内容以 Markdown 文件形式集中管理,站点结构和导航通过配置文件统一定义.这种结构使文档更易维护，也便于团队协作和版本管理。

### 2.配置灵活
* MkDocs 使用配置文件定义文档导航结构，而不是依赖文件目录结构自动生成导航。这种方式可以灵活控制页面顺序和层级，适合构建结构清晰的用户手册和开发文档。

### 3. 实时预览
* MkDocs 提供内置的本地开发服务器，支持实时预览。在编写或修改文档时，可以即时查看页面效果，提高文档编写效率。

### 4. 主题与插件扩展机制
* MkDocs 支持通过主题和插件扩展功能：主题用于控制站点的整体外观和布局,插件用于增强构建流程和功能。成熟的生态系统使 MkDocs 能够适配不同规模和风格的文档项目。
